# NIST FDS runs (experiment: exp/fds-microgravity-physics)

Real NIST FDS 6.11.1 runs used to calibrate the live g = 0 soot solver (`frontend/src/scene/microgravity.ts`).
Only the input decks are in git; FDS outputs (`*.sf`, `*.s3d`, `*.smv`, CSVs) are regenerated by the steps below.

## Install FDS (macOS)

The NIST installer `FDS-6.11.1_SMV-6.11.2_osx.sh` is a self-extracting archive. Unpacking it without the
interactive script (same as its option 2, `~/FDS/FDS6`):

```bash
S=~/Downloads/FDS-6.11.1_SMV-6.11.2_osx.sh; SKIP=$(awk '/^__TARFILE_FOLLOWS__/ { print NR + 1; exit 0; }' "$S")
mkdir -p ~/FDS/FDS6 && cd ~/FDS/FDS6 && tail -n +$SKIP "$S" | tar -xz --strip-components=1
```

The binaries are x86_64; on Apple silicon they run under Rosetta 2. Environment for a shell:

```bash
export PATH=$HOME/FDS/FDS6/bin:$HOME/FDS/FDS6/bin/openmpi/bin:$PATH OPAL_PREFIX=$HOME/FDS/FDS6/bin/openmpi \
  DYLD_LIBRARY_PATH=$HOME/FDS/FDS6/bin/openmpi/lib TMPDIR=/tmp OMP_NUM_THREADS=4
```

## Cases

Heptane, 30 % O2 (`Y_O2_INFTY=0.3286`), 101.3 kPa, 0.5 kW one-cell burner at the origin, `GVEC=0`,
the 8.5 m x 2.76 m x 2.76 m cabin aisle on a 0.25 m grid (35 x 11 x 11), 60 s, `DT=0.2` locked
(otherwise FDS grows the step to several seconds in near-still air), airflow +x at 0, 1, 4, 10, 20 cm/s
through supply/exhaust end walls. Each run takes about 5 s.

```bash
cd frontend
for f in 0 1 4 10 20; do
  npm run -s fds:deck -- --material Heptane --o2 30 --flow $f --dir +x --cell 0.25 --tend 60 --frames 20 \
    --hrr 0.5 --dt 0.2 --out ../fds_runs/heptane_o2_30_f$f/firetwin_iss.fds
  (cd ../fds_runs/heptane_o2_30_f$f && fds firetwin_iss.fds > fds.log 2>&1)
  npm run -s fds:slice -- ../fds_runs/heptane_o2_30_f$f --slice 1 --out ../fds_runs/heptane_o2_30_f$f/soot.json
done
npx vite-node scripts/calibrate_fds.ts                    # fit the live solver to these runs
npm run fds:slice -- ../fds_runs/heptane_o2_30_f10 --slice 1 --out public/fds/nist_real_slice.json
```

## What FDS showed (slice through the fire, PBY=0)

| airflow | soot centroid downstream (15 / 30 / 60 s) | cross-flow spread sigma | hot-zone aspect near the fire |
|---|---|---|---|
| 0 cm/s | 0 (reference) | 0.18-0.20 m | 1.4-1.7 (grid artefact; not used) |
| 1 cm/s | 0.12 / 0.20 / 0.30 m | 0.21-0.25 m | 1.05-1.15 (spherical) |
| 4 cm/s | 0.22 / 0.50 / 0.98 m | 0.21-0.23 m | 1.25-1.33 |
| 10 cm/s | 0.60 / 1.14 / 2.0 m | 0.21-0.22 m | 1.28-1.44 |
| 20 cm/s | 1.1 / 2.0 / 2.15 m (exits) | 0.20-0.22 m | 1.45-1.48 |

Calibration (`scripts/calibrate_fds.ts`, normalised L1 distance of the soot slice, 0 = identical, 2 = disjoint):
still air 1.05 -> 0.62, forced flow 1.16 -> 0.39. Fitted: `dStill = 1e-5`, `dForcedPerMS = 0.01`,
`expansionPerKw = 0.03` (physical scale HRR / (rho cp T) = 0.0028), flame stretch exponent 0.3, saturating
at 20 cm/s.

Limits: a 0.25 m grid cannot resolve a droplet flame (millimetres to centimetres), so the flame calibration
is the trend of the hot zone, not flame length. Soot uses FDS simple chemistry with a fixed soot yield.
